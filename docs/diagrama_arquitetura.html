Fluxos principais

1
Seleciona objeto
Usuário clica em objeto no Viewport → msgbus dispara callback automático
▶
2
Carrega Psets
props_load lê psets IFC do objeto via ifcopenshell e preenche OG_Properties
▶
3
Panel_Properties
Exibe propriedades, permite edição, gráficos e acesso a documentos
▶
4
bSDD / Catálogo
Opcional: consulta API bSDD para validar/enriquecer classes e propriedades
▶
5
Exporta IDS
Gera arquivo IDS para validação BIM ou salva propriedades no modelo IFC
